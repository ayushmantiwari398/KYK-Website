# KYK – Keep Your Kart
Multi-page shopping website made with HTML, CSS and JavaScript.

## Modules
- index.html – Home page with search and diagonal categories
- about.html – About KYK
- categories.html – Diagonal category layout
- products.html – Products and search
- gallery.html – Gallery
- contact.html – Contact form demo
- cart.html – Cart with remove option and total
- wishlist.html – Wishlist with add/remove
- account.html – Account demo page
- seller.html – Seller registration demo
- help.html – Help and support
- style.css – Common design
- script.js – Click actions, products, cart, wishlist and profile popup

## How to run
Extract the ZIP and open `index.html` in a browser. Keep all HTML files, `style.css` and `script.js` in the same folder. Internet is required for product photos.

## Notes
This is a frontend college project. Cart, wishlist and profile details are saved in browser localStorage. No real payment, backend, or database is connected.
